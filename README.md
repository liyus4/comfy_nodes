# comfy_nodes

ComfyUI用のカスタムノード詰め合わせリポジトリです。
入力ピンが動的に増減するUI拡張を活用した、テキストプロンプト切り替えに便利なノードと、キャラクターをランダム設計するノードが含まれています。

## 収録ノード

### 1. Dynamic String Selector

複数の文字列入力(`string_0`, `string_1`...)から、指定したインデックスの文字列を1つだけ選択して出力するノードです。

- **入力ピン（動的追加）**: このノードの `string_*` ピンに他のノード（文字列など）を接続すると、新しい空きピンが自動的に追加されます。接続を解除すると不要なピンは消えます。
- **パラメータ (`index`)**: 出力したい文字列のインデックス番号をINTで指定します。（例: 0を指定すると `string_0` が出力される）
- **特徴**: 出力前に、文字列内の `#` 以降（コメントアウト）を行末まで自動で削除します。

### 2. Batch Index Generator

複数のインデックス番号を指定して、**整数のリスト（バッチデータ）**として出力する専用ノードです。

- **パラメータ (`indices`)**: 出力したいインデックス番号をカンマやハイフンで指定します。
  - 例: `"2-5"` （index 2, 3, 4, 5 の4つの数値をリストとして出力）
  - 例: `"0, 2, 4-6"` （数値を指定順に 0, 2, 4, 5, 6 として出力）
  - 例: `"5-2"` （逆順指定も可能）
- **特徴**:
  - `Dynamic String Selector` の `index` 上で右クリックし、**「Convert index to input」** を選んでピン接続できるようにしてからこのノードの出力を繋ぐことで組み合わせて使います。
  - ComfyUIのバッチ処理機能が自動的に働き、1回のGenerateボタンで複数種の文字列プロンプトを順番に回して出力させることができます。

### 3. My Custom String Generator (Example)

基礎的なボイラープレートとして用意されたサンプルノードです。入力されたテキストを指定回数リピートして出力します。

### 4. Random Character Designer

軽い指示文（例: `悪魔・女の子・高露出`）と seed から、**人気キャラクターの設計手法に沿ったキャラクターを1体設計**し、ブレの少ないプロンプトを出力するノードです。API やネットワークは使いません（ルールベース・seed 完全再現）。

- **入力**（UI 上の名前は日本語です。括弧内は内部キー。`指示文` と `除外` は1行入力）
  - `指示文` (`brief`): 雰囲気の指示文。`・`/`,`/空白区切り。日本語・英語どちらでも可。辞書に無い語はそのままプロンプト末尾に通します。
  - `除外` (`exclude`): 出したくない語（例: `水着, バニー, 高露出, ヤンデレ`）。ランダム選択のプールからモチーフ/服装/性格/露出を外します。brief やドロップダウンで明示した指定は除外より優先されます。
  - `種族` (`motif`): 体の記号（耳・角・肌）と配色の軸。悪魔・天使・猫・エルフ・人形…・人間。`auto` 以外は brief より優先。
  - `モチーフ` (`theme`): 模様・小物・差し色の軸。星・炎・月・海・お菓子…。`自動` は指示文の指定があればそれ、なければ35%の確率で付きます（65%は「なし」と同じ結果）。`ランダム` は必ず付き、`なし` は付けません。指示文に「エルフ・星」のように書けば種族とモチーフの両方が立ちます。
  - `服装` (`role`): 服装系統をドロップダウンで固定（`auto` 以外は brief より優先）。
  - `装飾量` (`detail_level`): 服装の上に重ねる独自性のレイヤー。0 なし / 1 控えめ（小さなアドオン2つ）/ 2 標準（3つ＋象徴的な一点）/ 3 盛る（5つ＋象徴的な一点）。アドオンは7カテゴリ（非対称化: 片脚ニーソ・片手手袋・片側肩当て / ベルト・ストラップ: 太もも・二の腕・胸ハーネス・腰マント / モチーフ形状のハードウェア: `dragon-claw gauntlet`・`crescent-shaped pauldron` のように種族・モチーフの形状語で合成 / レイヤリング: 肩掛けジャケット・オーバースカート・コルセット / 切り抜き（標準露出のみ）/ 象徴的な一点: 巨大リボン・特大ヘッドホン・背中の浮遊リング・特大袖・機械の尻尾 / テック: 発光ライン・機械の片腕・バイザー）。部位スロットで衝突を避け、象徴的な一点は重み付き、文章「Her iconic design element is …」も出します。
  - `シルエット` (`silhouette`): ボリュームの偏り。上重心（ボリューム髪・広い袖）/ 下重心（ボリュームスカート・ロングコート）/ 縦長（超ロング髪・長いマント）/ 横広（大きな肩当て・広い袖）。`自動` は seed で決定。髪の個性と装飾レイヤーの選択がこれに寄り、情報量を集めるゾーン（頭/胸肩/腰/脚/腕のうち2つ）も決まります。文章「Design density is concentrated at …; … are kept plain」を出します。
  - `シェイプ` (`shape_lang`): シェイプ言語。丸（親しみ）/ 四角（安定）/ 鋭角（攻撃性）。`自動` は性格から（甘々・おっとり＝丸、委員長・熱血＝四角、ツンデレ・ドS・悪魔系＝鋭角）。反対の形（spikes / rounded design など）を negative に入れます。
  - `手持ち` (`handheld`): 武器・小道具。`なし`（既定。何も持たず、装飾が手持ち化しないよう negative に `holding object` を入れる）/ `ランダム` / `服装の小道具`（巫女の御幣・ナースの注射器など）/ 剣・刀・杖・短杖・魔導書・弓・槍・鎌・短剣・銃・盾・傘・扇・楽器・ランタン・鞭。種類（ロングソード/レイピア/大剣…）・刃や柄の色・鍔や石飾り・彫刻（モチーフの模様と連動）・鞘・持ち方まで seed で決め、booru タグ（sword / holding sword / sheathed…）と形状を固定する文章を出します。指示文に「剣」「刀」などを書いても付きます。
  - `胸` / `身長` / `体型` (`bust` / `height` / `build`): 体型の指定。胸は 0 flat chest 〜 5 gigantic breasts、6〜8 は booru の上限を超えるので重み（`(gigantic breasts:1.3〜2.0)`）と文章でさらに大きく押します。身長は とても低い〜とても高い、体型は 華奢/細身/普通/むっちり/ぽっちゃり/筋肉質。`自動` は従来どおり種族・性格の推奨です。
  - `服の色` / `髪の色` (`main_color` / `hair_color`): 服のメインカラーと髪色をドロップダウンで固定。`自動` は今までどおり種族・性格・服装の推奨パレットから組み合わせます。指定時も縁色（accent）などは推奨から補完されます。
  - `服装2` (`role2`): 2つ目の服装系統と融合します（`なし` / `ランダム` / 系統指定）。指示文に「シスター 忍者」のように系統を2つ書いても融合します。1つ目を土台（主役の服・丈・袖・露出の切り方）にして、2つ目からは頭・顔・手・首・羽織り・腰・識別タグ・小物だけを、部位が空いていれば取り込みます（頭・羽織り・足・脚は一定確率で2つ目側が勝ちます）。上下の服や袖はそのまま足さないので矛盾しません。
  - `シード` (`seed`): 同じ brief + seed なら必ず同じキャラになります。
  - `意外性` (`twist`): `王道`/`意外性`/`自動`。 `classic`=王道（悪魔→サキュバス）/ `surprise`=意外性（悪魔→シスター、悪魔なのに内気 など）/ `auto`=4割で surprise。
  - `露出` (`exposure`): 露出度（`auto` は brief の指定 > ランダム）。
  - `性格` (`personality`): 性格をドロップダウンで固定（`auto` なら brief かモチーフから選択）。
  - `出力形式` (`prompt_style`): `tags`（カンマ区切り）/ `natural`（文章）。
  - `再現性` (`consistency`): `strict`（既定）は booru の正規タグを骨格にし、色を main＋accent の2色に圧縮、縁色は `gold trim` のような1タグに集約、主役の服と記号に重み付け、別色の同じ服を negative に追加、フェイスペイントや肌の模様などの不安定要素は出力せずシートのメモに残します（Anima / Illustrious / Pony 系向け）。`full` は服1点ごとの詳細説明文です。
  - `強調` (`emphasis`): strict での重みの強さ（既定 1.6）。主役の服にそのまま、記号と性格の署名タグに ×0.9、目の形に強弱係数（0.85 / 1.0 / 1.15）を掛けて `(tag:1.6)` の形で付けます。Anima は SDXL より強い重みが必要（公式例 `(chibi:2)`）。1.0 以下で無効。
  - `目の形` (`eye_shape`): 目の形を固定（`auto` なら brief の指定 > 性格プロファイル）。
  - `表情ポーズ` (`expression_pose`): `expression_only`（既定。性格を表すデフォルト表情のみ）/ `both`（ポーズも含める）/ `none`。
  - `固定` + `キャラシート` (`lock` + `character_sheet`): 後述。
- **出力**: `positive` / `negative` / `character_sheet` / `seed`
  - 出力は**キャラの特徴だけ**です。品質タグ（masterpiece 等）・`solo`・`1girl`/`1boy`・画風・状況・品質系ネガティブ（lowres 等）は含めないので、別ノードのテキストと連結して使います。`negative` は「設計に無い記号（角・翼・眼鏡など）」露出度に応じた除外など、キャラの整合性に関わるものだけです。
- **同じキャラを再現する（lock）**
  1. 生成するたびに、設計内容が **`character_sheet` 欄にシートとして書き戻されます**（seed・コンセプト・パレット・設計メモ・positive・negative）。
  2. 気に入ったら `lock` を ON。以降は brief や seed を変えてもシートの内容がそのまま `positive` / `negative` に出力されます。
  3. シートは手で編集できます。`#` 以降はコメント、`# ── positive ──` / `# ── negative ──` の行でセクションが切り替わります。
- **開発用ホットリロード**: `character_designer/data.py` / `engine.py` を編集して保存すると、次の実行時に自動で再読み込みされます（ComfyUI の再起動不要）。`node.py`（入力欄の定義）と `js/` の変更は再起動とブラウザリロードが必要です。
- **設計手法（エンジンが適用するルール）**
  - **記号化**: モチーフごとの「一目で分かる記号」（角・翼・耳・光輪など）を必ず入れる
  - **テーマカラー3色**: main / sub / accent に制限し、縁取り・裏地・小物・瞳の色まで accent で固定
  - **服装のバリエーション**: 服装系統ごとに主役の服の選択肢や、無くても成立する小物（アイマスク・聴診器・鞄など）の有無が seed で変わる
  - **モチーフは衣装に溶かす**: モチーフの記号は髪飾り・イヤリング・ブローチ・刺繍・プリントなど身に着ける物だけ（手持ちの別物体は出さない）。手持ち小物には `holding` を付けて手に固定し、「モチーフは衣装の装飾として表現」の一文と negative（floating objects）で背景への散らばりを抑える
  - **露出アンカー**: 高露出のときは見せ場を2か所に絞り（sideboob / underboob / backless / see-through / bare shoulders / thighs / navel / bare back から seed で2つ、先頭だけ重み付き）「The exposure is focused on …; the rest stays covered」の自然文を添え、negative に `covered navel` 等を入れてモデルが穏当に描くのを防ぐ。`revealing clothes` は特定の衣装構造に引っ張られるため使わない
  - **配色比率の明示**: 「{main} 70% / {sub} 25% / {accent} 5%、残りは白・黒・金銀。瞳が最も彩度が高い」を文章で出す
  - **装飾カテゴリの拡充**: ダメージ加工（破れ・焦げ・継ぎ当て・包帯）、H型ハーネス・斜めベルト・二重ベルト・垂らしベルト、フェイクジッパー・チャーム・房飾り・鋲・ラインストーン・スパイク（シェイプ言語が丸なら鋲・スパイクは出ない）
  - **性格の署名**: 性格ごとに常に入るタグ（ドS: riding crop / evil smile / looking down at viewer、メスガキ: smug / fang など）と、性格を表す自然文1文を末尾に添える
  - **目の形の押し込み**: 目の形は画風に固定されがちなので、形タグに強弱3段階の重み、反対の形を negative、自然文での言い換え（upturned slanted eyes…）、大きさ軸（large round / almond-shaped / narrow / small）を組み合わせる
  - **目の構造化**: 色・形（ツリ目/タレ目/ジト目/三白眼）・開き具合・瞳孔（縦長/ハート/星/リング/収縮）・ハイライト（キラキラ/死んだ目/光る目）・まつ毛・眉・メイク・泣きぼくろ等を性格プロファイルから組み立てる。brief で「ツリ目」「死んだ目」「ハート瞳」「太眉」「赤シャドウ」などを直接指定可能
  - **髪の個性**: 装飾量に連動して、シルエット（hair wings・ハート型アホ毛・ヘアコーン・ヘアリング・鈴・浮遊する髪・超ロング・モチーフ形状の髪飾り）、配色（スプリットカラー・ツートン・毛先グラデ・インナーカラー・片側だけ色違い・染めた前髪）、結び方（折り返しポニテ・多段結び・縦ロール・クラウンブレイド）を足す。土台の髪型と結び方が衝突しないよう判定
  - **髪の構造化**: 色・長さ・質感・型・前髪・横髪・差し色/アホ毛を分けて指定し、再現時のブレを抑える
  - **性格の外見化**: 目の形（ツリ目/タレ目/伏し目）・髪型・表情・ポーズ・小物で性格を伝える（ツンデレ、甘々、メスガキ、清楚系、地雷系、内気、クーデレ、ヤンデレ、元気、お嬢様、お姉さん、ギャル、中二病、ボクっ娘、ドジっ娘、ドS、腹黒、不思議ちゃん、委員長、おっとり、熱血、毒舌、姉御、従順、臆病、自信家 の26種）
  - **ギャップ設計**: モチーフ × 意外な服装/性格で印象に残す
  - **シグネチャ小物**: その子だけの持ち物を1つ固定
  - **模様と細部の固定**: 服の模様を「スタイル＋モチーフ由来の模様」（例: small repeating bat-wing motif）として具体的に決め、配置場所・素材・縁の色・留め具・丈・レッグウェア・靴まで指定して再現性を担保

### 5. Browser Download Image

受け取った画像(`IMAGE`)を、**ブラウザの規定ダウンロードフォルダ**に PNG として保存させるノードです。

- サーバー側(Python)はブラウザの設定を知らないため直接は書けません。代わりに `PreviewImage` と同様に temp フォルダへ保存し、フロントエンド(`js/browser_download.js`)がブラウザにダウンロードさせています。保存先・「保存場所を毎回確認する」等の挙動はブラウザの設定に従います。
- `filename_prefix`: ファイル名の先頭。後ろに連番と `.png` が付きます。`SaveImage` と同じく `%date:yyyy-MM-dd-hh-mm-ss%` などの置換記法が使え、ワークフローが PNG メタデータに埋め込まれます。
- `add_timestamp`: ON（既定）で `filename_prefix` の後ろに実行時刻 `_YYYYMMDD_HHMMSS` を付けます（例: `ComfyUI_20261010_153045_00001_.png`）。
- 注意
  - ワークフローをキューしたブラウザのタブが開いている時だけダウンロードされます（タブを閉じた状態の実行では保存されません）。
  - バッチで複数枚になると、Chrome は初回に「複数ファイルのダウンロードを許可しますか」と確認します。一度許可すれば以降は自動で保存されます。
  - ノード上のプレビューは標準の画像表示なので、temp フォルダのファイルは ComfyUI 再起動で消えます。

## インストール方法

1. ComfyUIの `custom_nodes` ディレクトリに移動します。
2. このリポジトリをcloneします。
   ```bash
   git clone https://github.com/YourUsername/comfy_nodes.git
   ```
3. (依存ライブラリがある場合は `pip install -r requirements.txt` を実行します)
4. ComfyUIを再起動します。
