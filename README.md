# comfy_nodes

ComfyUI用のカスタムノード詰め合わせリポジトリです。
入力ピンが動的に増減するUI拡張を活用した、テキストプロンプト切り替えに便利なノードと、キャラクターをランダム設計するノードが含まれています。

## 収録ノード

### 1. Dynamic String Selector

複数の文字列入力(`string_0`, `string_1`...)から、指定したインデックスの文字列を1つだけ選択して出力するノードです。

- **入力ピン（動的追加）**: このノードの `string_*` ピンに他のノード（文字列など）を接続すると、新しい空きピンが自動的に追加されます。接続を解除すると不要なピンは消えます。
- **パラメータ (`index`)**: 出力したい文字列のインデックス番号をINTで指定します。（例: 0を指定すると `string_0` が出力される）
- **特徴**: 出力前に、文字列内の `#` 以降（コメントアウト）を行末まで自動で削除します。

### 2. Batch Index Generator

複数のインデックス番号を指定して、**整数のリスト（バッチデータ）**として出力する専用ノードです。

- **パラメータ (`indices`)**: 出力したいインデックス番号をカンマやハイフンで指定します。
  - 例: `"2-5"` （index 2, 3, 4, 5 の4つの数値をリストとして出力）
  - 例: `"0, 2, 4-6"` （数値を指定順に 0, 2, 4, 5, 6 として出力）
  - 例: `"5-2"` （逆順指定も可能）
- **特徴**:
  - `Dynamic String Selector` の `index` 上で右クリックし、**「Convert index to input」** を選んでピン接続できるようにしてからこのノードの出力を繋ぐことで組み合わせて使います。
  - ComfyUIのバッチ処理機能が自動的に働き、1回のGenerateボタンで複数種の文字列プロンプトを順番に回して出力させることができます。

### 3. My Custom String Generator (Example)

基礎的なボイラープレートとして用意されたサンプルノードです。入力されたテキストを指定回数リピートして出力します。

### 4. Random Character Designer

軽い指示文（例: `悪魔・女の子・高露出`）と seed から、**人気キャラクターの設計手法に沿ったキャラクターを1体設計**し、ブレの少ないプロンプトを出力するノードです。API やネットワークは使いません（ルールベース・seed 完全再現）。

- **入力**
  - `brief`: 雰囲気の指示文。`・`/`,`/空白区切り。日本語・英語どちらでも可。辞書に無い語はそのままプロンプト末尾に通します。
  - `seed`: 同じ brief + seed なら必ず同じキャラになります。
  - `twist`: `classic`=王道（悪魔→サキュバス）/ `surprise`=意外性（悪魔→シスター、悪魔なのに内気 など）/ `auto`=4割で surprise。
  - `exposure`: 露出度（`auto` は brief の指定 > ランダム）。
  - `personality`: 性格を固定したい時に指定（`auto` なら brief かモチーフから選択）。
  - `prompt_style`: `tags`（SD/Pony/Illustrious 向けカンマ区切り）/ `natural`（Flux/SD3 向け文章）。
  - `prefix`: 品質タグなどの接頭辞（空でも可）。
  - `lock` + `character_sheet`: 後述。
- **出力**: `positive` / `negative` / `character_sheet` / `seed`
- **同じキャラを再現する（lock）**
  1. 生成するたびに、設計内容が **`character_sheet` 欄にシートとして書き戻されます**（seed・コンセプト・パレット・設計メモ・positive・negative）。
  2. 気に入ったら `lock` を ON。以降は brief や seed を変えてもシートの内容がそのまま `positive` / `negative` に出力されます。
  3. シートは手で編集できます。`#` 以降はコメント、`# ── positive ──` / `# ── negative ──` の行でセクションが切り替わります。
- **設計手法（エンジンが適用するルール）**
  - **記号化**: モチーフごとの「一目で分かる記号」（角・翼・耳・光輪など）を必ず入れる
  - **テーマカラー3色**: main / sub / accent に制限し、縁取り・裏地・小物・瞳の色まで accent で固定
  - **性格の外見化**: 目の形（ツリ目/タレ目/伏し目）・髪型・表情・ポーズ・小物で性格を伝える（ツンデレ、甘々、メスガキ、清楚系、地雷系、内気、クーデレ、ヤンデレ、元気、お嬢様、お姉さん、ギャル、中二病、ボクっ娘、ドジっ娘、ドS の16種）
  - **ギャップ設計**: モチーフ × 意外な服装/性格で印象に残す
  - **シグネチャ小物**: その子だけの持ち物を1つ固定
  - **模様は1種類・細部固定**: 服の模様は1種類のみ、素材・縁の色・留め具・丈・レッグウェア・靴まで指定
- **brief で使える主な語**（抜粋。同義語は `character_designer/data.py` 参照）
  - モチーフ: 悪魔 / 天使 / 吸血鬼 / 魔女 / 猫 / 狐 / 狼 / 兎 / 竜 / 人魚 / 妖精 / 幽霊 / アンドロイド / 鬼 / 死神 / 羊 / 星 / 花 / 道化 / 人間
  - 服装: サキュバス衣装 / シスター / メイド / 制服 / ゴスロリ / 巫女 / 着物 / 騎士 / 魔女服 / ナース / アイドル / 魔法少女 / OL / 私服 / 水着 / バニー / 軍服 / お姫様 / チャイナ / ボディスーツ / 体操服 / 海賊 / 忍者 / 道化師 / パジャマ / 先生 / 踊り子 / 不良
  - 性別: 女の子 / 男の子　露出: 高露出 / 控えめ　色: 赤・青・黒… (テーマカラー)　髪: 黒髪・銀髪・ツインテール…　瞳: 赤目・オッドアイ…　体型: ロリ・長身・褐色・眼鏡…

## インストール方法

1. ComfyUIの `custom_nodes` ディレクトリに移動します。
2. このリポジトリをcloneします。
   ```bash
   git clone https://github.com/YourUsername/comfy_nodes.git
   ```
3. (依存ライブラリがある場合は `pip install -r requirements.txt` を実行します)
4. ComfyUIを再起動します。
